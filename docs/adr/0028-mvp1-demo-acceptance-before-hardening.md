# MVP1 Demo Acceptance Before Hardening

MVP-1 is accepted first as a playable locator workbench demo: paste input or rendered bundle, preview a page snapshot, select action targets, inspect the element chain, generate up to five locator candidates, recommend a unique candidate when possible, copy framework snippets, and use the minimal capture bookmarklet. Warning polish and unit test coverage are required hardening before moving into MVP-2, but they do not block the first playable demo.
