# Defer Manual Locator Candidates To Catalog Phase

Status: Superseded for MVP-2 by ADR 0029. MVP-2 now includes a temporary manual locator tester without saved catalog state.

Manual locator candidates are deferred from MVP-1 so the first workbench tests the generated candidate engine directly. Manual additions return in the catalog phase, where saved elements, validation warnings, and preferred candidate decisions have a durable home.
