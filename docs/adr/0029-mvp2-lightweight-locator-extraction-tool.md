# MVP2 Lightweight Locator Extraction Tool

MVP-2 continues the Locator Workbench as a lightweight extraction tool rather than turning it into a locator catalog. The primary job is to import or render a page snapshot, let the user click an element, generate ranked locators, test optional manual selectors, and copy framework snippets into their own codebase.

This supersedes the catalog direction for MVP-2. Project/page/element storage, IndexedDB catalog persistence, saved locator revalidation, project JSON import/export, and rename/delete catalog workflows are deferred until a durable catalog use case is proven separately.
